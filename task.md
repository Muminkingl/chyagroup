# Links Section UI Redesign (High Priority)

Please redesign the **Links** section across all company pages.

The current implementation works functionally, but as more links are added, the page becomes cluttered and difficult to navigate.

The goal is to create a modern, organized, and professional interface.

---

# Current Problem

At the moment, all links are displayed in one long list.

Example:

* Website
* Email
* Instagram
* Website
* Email
* Instagram
* Website
* Email
* Instagram

This becomes messy, especially for companies that have multiple contact methods.

---

# Required Solution

Instead of displaying one long list, group the links into categories.

Example:

## 🌐 Website Links

* Lama Al Marjan
* Chya Maiben
* Chya Amazon

---

## 📧 Email Addresses

* [lamatalmarjan2019@gmail.com](mailto:lamatalmarjan2019@gmail.com)
* [chyamateen2026@gmail.com](mailto:chyamateen2026@gmail.com)
* [chyaamazon2026@gmail.com](mailto:chyaamazon2026@gmail.com)

---

## 📸 Instagram

* @lamatalmarjan_oo
* @chya_mateen.oo
* @chya_amazon.iq

---

The design should automatically organize links into their appropriate category.

---

# Better Visual Design

Improve the overall appearance by using:

* Category cards
* Category icons
* Clear section headings
* Better spacing
* Consistent typography
* Hover effects
* Modern rounded cards
* Better visual hierarchy

Each category should feel like its own section instead of everything appearing in one continuous list.

---

# Better Link Cards

Each individual link card should display:

* Platform icon
* Link title
* URL, username, or email
* Open/Visit button
* Hover animation

The cards should be compact while remaining easy to read.

---

# Responsive Design

The layout must be fully responsive.

### Desktop

Display categories in a clean multi-column layout where appropriate.

### Tablet

Adjust spacing and card sizes naturally.

### Mobile

Stack categories vertically with proper spacing and touch-friendly controls.

Nothing should overflow or become difficult to use.

---

# Future-Proof Design

The UI should automatically support new link types without requiring a redesign.

If additional platforms are added later, they should appear in their own category automatically.

---

# Empty Categories

If a company does not have any links for a specific category, do not display that category.

Example:

If there are no Facebook links, hide the Facebook section entirely.

---

# Expected Result

The Links section should feel clean, organized, and professional.

Instead of one long mixed list, users should immediately understand where to find:

* 🌐 Websites
* 📧 Email Addresses
* 📸 Instagram
* Any future social media or contact methods

The overall experience should resemble a modern company profile page, with excellent readability and responsiveness across desktop, tablet, and mobile devices.
